# 점심 장부 — 배포 방법 (B1: 구글 시트 + Apps Script)

페이지와 데이터를 **구글 Apps Script 웹앱 하나**로 처리합니다.
별도 호스팅 불필요. 공용 암호 없음 — 링크 아는 사람은 누구나 접속·평가.

## 파일

| 파일 | 역할 |
|---|---|
| `Code.gs` | 백엔드. 페이지 서빙 + 시트 읽기/쓰기 |
| `Index.html` | 화면 전체 (별점 UI). Apps Script 프로젝트에 `Index`로 넣어야 함 |

## 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 빈 스프레드시트 생성. 이름은 아무거나 (예: `점심 장부`).
2. `places` / `reviews` 탭은 **직접 안 만들어도 됨** — 스크립트가 처음 실행될 때 자동 생성합니다.

## 2. Apps Script 코드 넣기

1. 그 시트에서 **확장 프로그램 → Apps Script**.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 내용을 붙여넣기.
3. 왼쪽 **파일 + → HTML** 로 새 파일을 만들고 이름을 `Index` 로 지정
   (자동으로 `Index.html` 이 됨). 그 안에 이 폴더의 `Index.html` 내용을 붙여넣기.
4. 💾 저장.

## 3. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴 ⚙ → **웹 앱** 선택.
3. 설정:
   - 설명: 아무거나
   - **실행 계정: 나 (본인 이메일)**
   - **액세스 권한: 모든 사용자**  ← 링크만 알면 접속되게 하는 핵심
4. **배포** → 처음이면 권한 승인 창이 뜸.
   "고급 → (안전하지 않음) 이동" 을 눌러 본인 구글 계정 권한을 허용.
   (내 시트에만 접근하는 내 스크립트라 정상입니다.)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사.
   → 이 링크를 동료들에게 전달하면 끝.

## 4. 코드 수정 후 재배포

`Code.gs` 나 `Index.html` 을 고치면:
**배포 → 배포 관리 → (기존 배포) 연필 아이콘 → 버전: 새 버전 → 배포**
그래야 `/exec` URL에 반영됩니다. (URL은 그대로 유지)

## 데이터 구조 (시트에서 바로 보임)

**`places` 탭**

| id | name | category | address | createdAt |
|---|---|---|---|---|

**`reviews` 탭**

| id | placeId | taste | price | mood | service | hygiene | comment | createdAt |
|---|---|---|---|---|---|---|---|---|

- `placeId` 가 `places.id` 와 연결됨.
- `taste`=맛, `price`=가성비, `mood`=분위기, `service`=서비스, `hygiene`=위생 (각 1~5).
- 화면의 종합점수 = 이 다섯 항목 평균. 손으로 행을 지우거나 고치면 화면에도 반영됨.

## 참고 / 한계

- **실시간 아님**: 남이 넣은 평가는 최대 6초 뒤(자동 새로고침) 반영.
- **익명**: 누가 평가했는지는 저장하지 않음.
- 한 사람이 같은 가게를 여러 번 평가할 수 있음 (모두 평균에 포함).
- 시트/스크립트 **소유자 = 만든 사람**. 인수인계하려면 스프레드시트 소유권 이전 필요.
- 무료 구글 계정 기준 하루 실행/요청 한도가 넉넉해 3~5명 사용엔 문제 없음.
